# review_log.md — Are Data Centers Raising Your Electric Bill?

审片共 **3 轮**（每轮都重渲染后再看）。我没有声卡，音频只做数值检查；画面检查 = 每 2–3 秒抽一帧 + 每个场景切换点 + 每句开头 + 每个关键数字"到位后 1.6 秒"的帧，做成带时间戳的 3×4 联系表逐张看，再加 `review.py` 的自动检查（见下）。

工具：`review.py`（把每段场景画到透明画布上，量墨迹离边缘多远 / 空屏 / 画面多久没变）、`frames.py`（抽帧 + 联系表）、`check_text.py`（旁白 = timeline.json = 核查稿附录；SRT 合理性）、`check_audio.py`（响度外的数值检查）。

## 第 1 轮（初版 v1，10:52）
发现并已改：
1. **边缘不足 80 px**：开头两张剪报（左 67 / 右 70 px）、3.7 的剪影名牌（左 64 px）、5.6 的印章（底 y=959，压到字幕区）→ 全部内移。
2. **空屏 > 1 s**：4.4 → 4.5 之间 5 秒（490–495 s）、4.7 之间 1.5 秒（529–531 s）→ 卡片提前上屏。
3. **画面超过 8–10 秒没有新信息**：20 个窗口（开头 5–15 s、拍卖原理图 88–97 s、2.4 / 2.5 / 2.7 / 2.9 / 3.3 / 3.7 / 3.8 / 3.12 / 3.14 / 4.2 / 4.5 / 4.8 / 5.2–5.4 / 6.4 / 6.5 …）→ 加了 30 多处节奏点（红笔圈 / 下划线 / 逐条出现的要点 / 箭头 / 第二张卡片 / 小印章），自动检查从 20 个窗口降到 1 个。
4. **响度**：配音波峰比响度高约 20 dB，−1 dBTP 的上限把响度压在 **−15.3 LUFS**，达不到 −14。加了温和压缩 + 限幅器（`mix.py` 的 PRE）再两遍 loudnorm → 约 −14.1 LUFS；后来把真峰值目标从 −1.1 收到 −1.5（AAC 编码会多出一点），最终成片 **−14.2 LUFS / 真峰值 −1.3 dBTP**（见下）。
5. 字幕：不允许停在虚词上（an / the / of / until / 数字+单位拆开等）→ `subs.py` 加规则。

## 已知但不影响观看的小瑕疵（不再返工）
1. 开头 $329 / 10× 比旁白提前 2–4 秒出现（为满足"10× 5 秒内"）。
2. 3.12（437–445 s）画面变化较小。
3. 字体：Mac 上没有 Inter，改用 Arial Bold / Arial（版式更宽一点）；数字仍用 IBM Plex Mono Bold。
4. **没有听过成片**：Kokoro 对 "E P R I"、"I E E F A"、"P J M"、"D C"、"Politi-Fact" 的读法只能按脚本的拼读规则保证，实际听感请你抽查；配音还加了温和压缩 + 限幅器，可能略有"压"的感觉。
5. 场景之间的 0.8 秒平移是设计（拼贴墙平移），平移时前后两段内容会同时在画面里，但不是同一类卡片的叠放。
6. 少数字幕条里含两句话（时间 3–4 秒），没有再拆。
7. 画面里的"gray ? 占位"（"+?%"）是有意设计：旁白念到之前不显示数字。
