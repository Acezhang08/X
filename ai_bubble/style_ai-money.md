# style_ai-money.md — “AI 的钱”系列固定画风（报纸拼贴 + 动态数据图表）

第一次用于：*The AI Bubble, Explained: Follow the Money*（2026-10-11 选题）。以后这个系列沿用。

## 技术底座
- 渲染：Python + skia-python 逐帧绘制（纯函数 `draw(t)`，可随机寻帧、可多进程并行），ffmpeg 编码。画幅 1920×1080、30fps、H.264 + AAC。
- 工具库：`lib.py`（纸张、剪报 `card()`、印章 `stamp()`、箭头 `arrow()`、红笔 `pen_ellipse()`、钞票/芯片/厂房/电塔/插头/服务器/账本线稿、剪影、搜索框、柱状图）。场景在 `scenes_a/b/c.py`，时间轴来自 `timeline.json`（配音实测）。
- 内容区：y ∈ [30, 900]。**底部 y > 930 留给字幕**，任何图表/数字都不得进入。

## 纸张与颜色（每种颜色含义固定）
| 用途 | 色值 |
|---|---|
| 底色（旧新闻纸，代码生成噪点+纤维+暗角） | #EFE9DD（剪报纸 #F7F2E7） |
| 墨黑：普通文字、线条 | #1C1C1C |
| 美元绿：钱的流向、资金箭头、收入 | #2F7D4A |
| 警示红：债务、风险、亏损、破产（少用） | #C23B22 |
| 琥珀：关键数字、要观众记住的点 | #D99A1E |
| 灰：背景信息、过去的年份（回到 1999/2001 时整体再叠一层泛黄色调） | #8A857C（深灰 #6F6A60） |

## 字体
- 剪报标题：Playfair Display（粗体用 embolden）。**Playfair 的数字是旧式数字，数字一律改用 Inter Bold 绘制**（`lib.text()` 已自动处理）。
- 正文/标签：Inter；大数字：IBM Plex Mono Bold；中文（抖音版字幕）：文泉驿正黑。
- 画面内文字最小 32px（来源小字也是 32px）。

## 元素语言
- **剪报** `card()`：撕边、胶带、±3° 倾斜、投影；贴上（轻微放大回弹）/ 揭下（上飘、旋转、淡出）。
- **印章** `stamp()`：公司名只用文字印章，不用 logo；“砸”下来的动画（放大 1.7× → 1×）。
- **箭头**：逐段“画”出来；钱的流向用美元绿；钞票是极简线稿（不画真实钞票图案）沿箭头移动。
- **红笔**：圈数字、划线、×2 等批注，手绘抖动（DiscretePathEffect）。
- **人物**：只用黑色剪影 + 名字标签，不放照片。
- **剪报内容规则**：标题只写我们自己的事实句；不用任何真实报纸报头/字体/版式；每张带具体数字的剪报或数字面板，角落一行来源小字（`Source: …`）。
- **示意内容**必须标 `illustrative`；预测/估算必须标 `projected` / `Burry's estimate` 之类。
- **镜头**：不用花哨转场，用“拼贴墙平移”（段与段之间 0.8 秒平移，背景有随镜头移动的淡色旧剪报碎片），段内可平移/上下追拍（如 4.7 的高柱）。
- **节奏**：每 20–30 秒至少一次明显的视觉变化；核心画面（钱转圈）放慢。

## 字幕
- 白字 + 细黑描边（英文 4px、中文 3.4px）+ 轻微阴影；无边框、无底色块。
- 英文 44px Inter Bold，中文 40px。YouTube 版只有英文（y=1008）；抖音版英上中下（y=968 / 1032）。
- 每条字幕最多一行（英文 ≤ 1640px）；长句按标点/词边界拆成多条，时间按字符比例分配。

## 复用清单
`lib.py`、`timeline.py`（Timeline：`s()/e()/w()` 取句子起止与词出现时间）、`subs.py`、`render.py`、`render_all.py`、`mix.py`、`music.py`、`thumbs.py`。新视频只需替换 `script.py`、重新跑 `tts.py`，再写新的 `scenes_*.py`。
